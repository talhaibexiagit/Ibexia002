**AppAuditor
Project Overview**

AppAuditor is an Android application built using Kotlin and Jetpack Compose.
The goal of this project is to analyze installed applications on a device.

**Current Feature (Sprint 1)**
Fetches all user-installed applications using Android PackageManager
Filters out system applications
Displays the list of user apps in Logcat

**Tech Stack**
Kotlin
Jetpack Compose
MVVM Architecture
Android PackageManager API
